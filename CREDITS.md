# Credits

uBomber is an open-source maze-bomber arcade game set in Stockholm.

## Concept & Direction

- **Jackson Mafra** — project owner, game direction

## Genre Heritage

uBomber belongs to the maze-bomber genre pioneered in the 1980s. It is an
original work: all names, characters, art, audio and arena layouts in this
project were created from scratch for uBomber. No assets, trademarks or
recordings from any other game are used, and the game is not affiliated with or
endorsed by any other game or rights holder.

## Art & Audio

- All floor tilesets, block faces, characters, bombs, blasts, power-up icons,
  skylines and particle palettes are procedurally generated by code in this
  repository. There are no image assets.
- All sound effects, ambient beds and music are synthesized at runtime with the
  Web Audio API. There are no recordings and no sample libraries.

## Typography

- [Familjen Grotesk](https://fonts.google.com/specimen/Familjen+Grotesk) —
  display (SIL OFL 1.1)
- [Martian Mono](https://fonts.google.com/specimen/Martian+Mono) — numerals and
  mono accents (SIL OFL 1.1)

Both are loaded from Google Fonts; the UI falls back to the system sans-serif if
they are unavailable.

## Setting

The ten arenas are affectionate interpretations of real places in Stockholm,
Sweden — from Gamla Stan to the archipelago. No affiliation with or endorsement
by any depicted location, institution or operator is implied.
